# 端到端回归测试（数据流整链）

一条命令，无浏览器、无外部服务，可直接当回归门禁：

```bash
npm install        # 首次（只为装 typescript，测试本身零新增依赖）
npm run test:e2e   # 或 npm test
```

- 通过：TAP 输出 `# pass N`，退出码 0。
- 失败：打印 `[环节] 断言点｜姓名（行号，id）` 与期望/实际差异，退出码非 0。
- 原理：`tsc` 把 `src/logic` 与测试编译成 CommonJS（`tests/e2e/.build/`），跑 Node 内置 `node:test`。不引入任何新依赖。

## 钉住的链路

```
录入(analyzeDraft) / 导入(CSV→dry_run→applyImport)
  → 半厘米归一(precision) → 档位与型别(sizeRules) → 归并(runMerge)
  → 分档小计与守恒(buildSummary) → 页面小计(SummaryView 同源)
  → 下单汇总表 / 量体明细 / 打印稿(exporter) → CSV / XLSX 文件(csv/xlsx)
```

| 文件 | 覆盖 |
| --- | --- |
| 01-entry-import | 录入校验分级（无效/待确认）、重复行只提示不删；100 行含 5 错误的 dry_run 行号定位；正式导入计数；文件指纹幂等 |
| 02-precision | 0.5cm 归一；半厘米一律整数比较；浮点尾差（0.1+0.2、167.5±1e-12）不改变判定；档位对齐 1004 点全域穷举对照暴力参考 |
| 03-boundary-fit | 167.5/182.5/162.5、胸围 86/90 在归上/就近下必须不同（可证伪）；边界两侧一致；型别区间端点闭区间、空隙与负值不可归并；男女不同标准；规则版本锁定 |
| 04-conservation | 500 行含 3 无效时守恒等式；班级/批次小计合计；1 条未归并 → 导出被阻止并定位到行；标记特殊后恢复；重复排除后仍守恒 |
| 05-override | 覆写与规则冲突时人数套数以覆写为准；覆写后守恒成立；留痕进明细；重跑归并不丢覆写；撤销回规则结果；非法号型拦住 |
| 06-three-way | 页面汇总 vs 下单汇总表 vs 量体明细 vs 打印稿 四处一致；独立直方图双记账；CSV/XLSX 逐格回读一致 |
| 07-export-format | CSV BOM/逗号/引号/换行无损往返；XLSX 数值格与文本格不混、全列类型一致；空单元格不占位、不出现 "null" 文本 |
| 08-legacy-archive | 旧存档缺字段的兼容与拦住（见下）；规范化幂等；坏存档不拖垮其它项目 |
| 09-scale-perf | 5000 人：导入解析+校验 < 2s、归并 < 200ms（规格书 §8）；整链耗时打进 TAP 诊断；两次运行 CSV 逐字节、XLSX 逐格一致；归并幂等 |

## 基准决策：以页面汇总为基准，导出为被测对象

**本组测试以 `buildSummary` 的输出（即页面小计）为唯一事实源**，下单表、明细、打印稿、CSV/XLSX 都是它的投影，一致性断言的方向是「导出 == 页面」。

- 为什么：守恒校验与导出闸门（`blocked = !conserved`）都挂在页面汇总上，操作员最终拿页面与服装厂对账；导出只是同一份数据的搬运。以页面为基准时，文件层 bug（CSV 转义、XLSX 类型）与业务错误能在失败信息里自然分开。
- 代价：页面本身算错时，所有导出会「一致地错」，一致性断言全绿却结论错误。
- 对冲：每条链都配**不经过 `buildSummary` 的独立不变量**——从 `persons` 原始数据直算的直方图（双记账）、守恒等式、档位/型别的全域穷举与端点用例。页面错会栽在这些断言上。
- 反向路线（以导出为基准、页面当被测对象）的代价：文件格式层的任何抖动都会淹没业务断言，且「页面显示 ≠ 文件内容」时无法判定哪边错；适用情形是只做文件级回归、没有页面运行环境（例如只交付 CSV 给下游）。本项目页面与文件同源同进程，没有采用反向路线的必要。

## 旧存档缺字段：兼容还是拦住

`src/logic/migrate.ts`（已接入 `initStore`）的契约，由 08 锁定：

| 情况 | 策略 |
| --- | --- |
| 缺可选字段（batch/note/anomaly/imports/perf/sourceRow…） | **兼容**：补默认值，照常进链 |
| 旧版 result / 人工覆写（缺 at、ruleSizeCode） | **兼容**：覆写保留，重跑归并补全规则号型；缺时间戳记 0，不伪造 |
| 缺测量值（身高/胸围/腰围为 0） | **拦住（链路）**：保持有效行，走「未归并 → 守恒不通过 → 禁止导出」，人工补录后恢复 |
| 缺性别等无法补全的关键字段 | **拦住（行级）**：保留该行但标无效，不计入有效人数，原因留痕 |
| persons 里的非对象条目 | **拦住（行级）**：占位无效行，总录入行数不变 |
| 记录非对象 / 无 id / persons 非数组 | **拦住（整条）**：拒绝该条存档，不影响其它项目加载 |
| 缺 ruleVersion | **兼容**：落到内置首版规则，汇总标注实际版本 |

## 已知边界

- XLSX **导入**解析（`readXlsxRows`）依赖浏览器 `DOMParser`，不在 Node 链内；其下游（dry_run → 归并 → 汇总）与 CSV 完全同路，已由 01/09 覆盖。XLSX **导出**由验证侧读取器逐格回读覆盖（06/07）。
- `store.ts` / `idb.ts`（IndexedDB 持久化）依赖浏览器，不在编译范围内；`migrate.ts` 的规范化逻辑直接单测（08）。
- XLSX 文件字节含打包时间戳，两次运行不保证字节相同；确定性断言比的是逐格内容（09）。
